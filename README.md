# Gemini AI Prompt Engineering

## Aim
To establish a working environment for prompt engineering and communicate with Google's Gemini AI model using Python.

## Technologies Used
- Python
- Google Colab
- Gemini API
- Google Gen AI SDK

## Problem Statement
To load a Gemini API key securely, send a prompt to an AI model, display its response, and handle errors.

## Prompt
"What is prompt engineering? Answer in one sentence."

## Procedure
1. Open Google Colab.
2. Install the `google-genai` library.
3. Create a Gemini API key using Google AI Studio.
4. Store the API key in Colab Secrets as `GEMINI_API_KEY`.
5. Run the Python program.
6. Display the model's response.

## Expected Output
- Environment ready message
- Prompt displayed
- Gemini AI response displayed

## Result
The program demonstrates how to connect to the Gemini API, send a prompt, and display the generated response.

## Security
Never upload API keys, passwords, or other secrets to GitHub.
